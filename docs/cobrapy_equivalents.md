# cobrapy equivalents

MATLAB functions that need no translation because cobrapy already covers them.
These snippets come from the PSCM workbench. They are usage examples
(names like `model` and `met_ids` stand for your own objects), not importable code.
Generated by `tools/export_workbench.py`; edit in the workbench.

## addDemandReaction

cobrapy provides: Model.add_boundary(type="demand") (cobra.core.model). Default id is DM_<met id> with lb 0 and ub = configuration.upper_bound (1000 by default).
Differences from MATLAB: whole-body models use 1e6 bounds; pass ub explicitly if needed. Adding an id that already exists raises; MATLAB behaviour for duplicates not checked.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: model = addDemandReaction(model, metaboliteNameList)
for mid in met_ids:
    model.add_boundary(model.metabolites.get_by_id(mid), type="demand")   # id DM_<met>, lb 0
```

## addExchangeRxn

cobrapy provides: Model.add_boundary(type="exchange") (cobra.core.model). Default id EX_<met id>.
Difference to check before using on WBMs: add_boundary raises ValueError if the metabolite is not in the compartment cobrapy detects as external (find_external_compartment). Whole-body models have several external-like compartments ([e], [bc], [u], [d], ...). If it raises, use type="sink" with reaction_id=f"EX_{met_id}" or build the Reaction directly.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: model = addExchangeRxn(model, metList, lb, ub)
for mid, lo, hi in zip(met_ids, lbs, ubs):
    model.add_boundary(model.metabolites.get_by_id(mid), type="exchange", lb=lo, ub=hi)  # id EX_<met>
```

## addSinkReactions

cobrapy provides: Model.add_boundary(type="sink") (cobra.core.model).
Differences from MATLAB: cobrapy's default id prefix is SK_; PSCM code matches on 'sink_', so pass reaction_id=f"sink_{met_id}". Default bounds come from configuration (+/-1000); pass lb/ub.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
```

## changeObjective

cobrapy provides: Model.objective setter (cobra.core.model). Accepts a reaction id, Reaction, or {Reaction: coefficient}; replaces the whole objective (set_objective(..., additive=False)), as changeObjective zeroes model.c first.
Differences from MATLAB:
- Unknown reaction id raises ValueError("invalid objective"); MATLAB prints and drops missing ids from a list.
- To verify: whether the objective direction is kept. The setter calls set_objective in cobra.util.solver, which is not in the project files. If not, set model.objective.direction = "max"/"min" afterwards.
- Do not use reaction.objective_coefficient: its setter is additive and keeps the old objective (cobra.core.reaction source).

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: model = changeObjective(model, rxns, objectiveCoeff)
model.objective = {model.reactions.get_by_id(r): c for r, c in zip(rxns, coeffs)}
# single reaction, coefficient 1:  model.objective = "Whole_body_objective_rxn"
```

## changeRxnBounds

cobrapy provides: Reaction.bounds / lower_bound / upper_bound setters (cobra.core.reaction); knock_out() sets (0, 0). The MATLAB list form is a loop over these calls.
Differences from MATLAB:
- _check_bounds raises ValueError whenever lb > ub, checked against the current other bound. Set (lb, ub) together with .bounds when both change.
- Unknown id raises KeyError (get_by_id); MATLAB warns and continues.
- MATLAB errors on mismatched list lengths; loop code must check lengths itself.
- Changes are reverted on exit inside `with model:`.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: model = changeRxnBounds(model, rxnNameList, value, boundType)
# 'b' (both):
for rid in rxn_ids:
    model.reactions.get_by_id(rid).bounds = (value, value)
# 'l' or 'u' on one reaction: keep the other bound
rxn = model.reactions.get_by_id(rid)
rxn.bounds = (new_lb, rxn.upper_bound)   # 'l'
rxn.bounds = (rxn.lower_bound, new_ub)   # 'u'
```

## deleteModelGenes

cobrapy provides: cobra.manipulation.knock_out_model_genes(model, gene_list) -> List[Reaction] (cobrapy docs). Evaluates each GPR and sets bounds to zero when the knock-out stops the reaction; reverted inside `with model:`.
Differences from MATLAB: no downRegFraction (partial knock-down); if a translation needs it, scale the returned reactions' bounds instead of zeroing.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
from cobra.manipulation import knock_out_model_genes
# MATLAB: [model, hasEffect, constrRxnNames] = deleteModelGenes(model, geneList)
knocked_out = knock_out_model_genes(model, gene_ids)   # returns reactions set to (0, 0)
has_effect = bool(knocked_out)
constr_rxn_names = [r.id for r in knocked_out]
```

## fluxVariability

cobrapy provides: cobra.flux_analysis.flux_variability_analysis.
Differences from MATLAB: returns a DataFrame indexed by reaction id with 'minimum'/'maximum' columns; optPercentage is a fraction (0-1); loopless FVA via loopless=True.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
from cobra.flux_analysis import flux_variability_analysis
# MATLAB: [minFlux, maxFlux] = fluxVariability(model, optPercentage, osenseStr, rxnNameList)
model.objective.direction = "max"   # cobrapy ignores 'max'/'min' strings in optimize(); set direction directly
fva = flux_variability_analysis(model, reaction_list=rxn_ids, fraction_of_optimum=opt_percentage / 100)
min_flux, max_flux = fva["minimum"], fva["maximum"]
```

## getObjectiveSense

cobrapy provides: model.objective.direction ('max'/'min'); osense = -1 if 'max' else 1. Used directly by optimize_cb_model.
Reminder: model.optimize(objective_sense=...) only accepts 'maximize'/'minimize'; set model.objective.direction directly.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: [osenseStr, osense] = getObjectiveSense(model)
osense_str = model.objective.direction            # 'max' or 'min'
osense = -1 if osense_str == "max" else 1         # MATLAB convention: -1 maximise, +1 minimise
```

## minimizeModelFlux

cobrapy provides: cobra.flux_analysis.pfba (minimise total flux at the optimum).
Differences from MATLAB: no irreversible model (modelIrrev) is built or returned; result is a cobrapy Solution.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
from cobra.flux_analysis import pfba
# MATLAB: [MinimizedFlux, modelIrrev] = minimizeModelFlux(model, osenseStr, minNorm)
solution = pfba(model)            # fraction_of_optimum=1.0 by default
fluxes = solution.fluxes          # minimised fluxes
total_flux = solution.objective_value   # sum of |v|, MATLAB MinimizedFlux.f
```

## solveCobraLP

cobrapy provides: Model.optimize() / slim_optimize() (cobra.core.model) on the model's own solver problem.
Hybrid design (agreed): optimize_cb_model keeps the MATLAB structure but works on the cobrapy model and its solver; no optProblem struct. optimize_cb_model calls model.optimize() through its _solve helper, which turns the cobrapy Solution into MATLAB's fields (stat codes, osense-signed duals, slack) following this function's MATLAB source.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: solution = solveCobraLP(LPproblem, param)
solution = model.optimize()       # cobra Solution: objective_value, status, fluxes, shadow_prices, reduced_costs
value = model.slim_optimize()     # objective value only; NaN if not optimal
```

## solveCobraQP

cobrapy provides: Model.optimize() with a quadratic objective; get_solver_name(qp=True) picks a QP-capable solver. From the MATLAB source: solveCobraQP minimises osense*c'x + 0.5x'Fx (only the linear part changes sign for a maximisation).
Hybrid design (agreed): optimize_cb_model keeps the MATLAB structure but works on the cobrapy model and its solver; no optProblem struct. optimize_cb_model calls model.optimize() through its _solve helper, which turns the cobrapy Solution into MATLAB's fields (stat codes, osense-signed duals, slack) following this function's MATLAB source.

```python
# In CobraPy: no translation needed. Use this cobrapy code directly.
# MATLAB: solution = solveCobraQP(QPproblem)   -- always minimises osense*c'x + 0.5*x'*F*x
from cobra.util.solver import get_solver_name, interface_to_str, qp_solvers
if interface_to_str(model.problem) not in qp_solvers:
    model.solver = get_solver_name(qp=True)        # MATLAB: CBT_QP_SOLVER
model.objective = model.problem.Objective(quadratic_expression, direction="min")
solution = model.optimize()
```
